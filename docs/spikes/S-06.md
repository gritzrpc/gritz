# S-06: Async transport interoperability

- Date: 2026-10-02.
- Status: Pending; no interoperability result is claimed.

The [RubyGems metadata](https://rubygems.org/gems/async-grpc) returned async-grpc
0.10.0 (released 2026-09-24). The [upstream README](https://github.com/socketry/async-grpc/blob/main/readme.md)
documents all four RPC patterns and its Async::HTTP/Protocol::GRPC stack.
These upstream capabilities have not been tested with Gritz.

The remaining experiment must pin async-grpc and protocol-grpc versions,
use protoc-generated message classes, and implement unary, server streaming,
client streaming and bidi handlers. Call each using grpc 1.83.0 and grpcurl
1.9.4; inspect status codes, initial metadata, trailers,
`grpc-status-details-bin`, deadlines, cancellation and message order. Bind a
socket in a clean parent and verify a forked child can serve that inherited FD.

No async gems were added to production dependencies and no adapter is claimed
complete. Acceptance requires recorded wire results and the shared transport
contract, not upstream feature documentation.
