# S-05: Protobuf descriptors for reflection

- Date: 2026-10-02.
- Environment: Linux Ruby 3.4.11 and macOS Ruby 4.0.6, protobuf 4.36.2.

```sh
ruby spikes/s05_descriptors/probe.rb
```

Generated `echo_pb.rb` calls `DescriptorPool.generated_pool.add_serialized_file`.
A prepend hook captured the bytes before forwarding the unchanged call. The
bytes decoded into the expected package and service, then survived an
encode/decode round trip with equal content. The regenerated streaming descriptor
uses a different but semantically equal byte encoding. `Echo::EchoRequest.descriptor.file_descriptor.to_proto` also returned
an equal FileDescriptorProto directly. [Raw result](results/s05_linux.json).

Descriptor extraction is feasible on protobuf 4.36.2. Prefer direct `to_proto`
when the supported protobuf versions expose it; capture serialized descriptors
only when needed. Capturing hooks must run before generated definitions load.

The reflection wire server, transitive import traversal, built-in descriptors,
`grpcurl list`/`describe`, custom options and older protobuf versions remain
untested. S-05 is partial until those checks pass; it does not claim that
reflection is implemented in the initial release.
